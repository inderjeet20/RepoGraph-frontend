# RepoGraph — Frontend

> **"We are going to show you full flow of your repository like git in a beautiful manner, it's RepoGraph"**

A minimal, clean, neutral React frontend for **RepoGraph**.

## Features

- Neutral, clean, minimal design
- Dark & Light mode toggle with persistent state
- Air Force Blue primary accent color
- Poppins & JetBrains Mono typography
- Fast build & dev workflow with Vite, React, and Tailwind CSS

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
